# Model Evaluation and SHAP Interpretation Project

This project demonstrates a classification workflow using scikit-learn's Wisconsin Diagnostic Breast Cancer dataset.

## Project structure
```text
README.md
notebooks/model_interpretation.ipynb
docs/evaluation_report.md
assets/confusion_matrix.png
assets/roc_curve.png
assets/feature_importance.png
assets/test_predictions.csv
assets/shap_summary.png          # generated by running the notebook
assets/shap_force_plot.html      # generated by running the notebook
requirements.txt
```

## Step-by-step setup (Windows)
1. Install Python 3.10 or 3.11 from https://www.python.org/downloads/ and select **Add Python to PATH**.
2. Extract this ZIP file to a folder.
3. Open Command Prompt in the extracted project folder.
4. Create and activate a virtual environment:
   ```bat
   py -3.11 -m venv .venv
   .venv\Scripts\activate
   ```
5. Upgrade pip and install dependencies:
   ```bat
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
6. Start Jupyter with `jupyter notebook`.
7. Open `notebooks/model_interpretation.ipynb` and run cells from top to bottom.
8. Evaluation plots are saved in `assets/`; SHAP cells generate `shap_summary.png` and `shap_force_plot.html`.
9. Review `docs/evaluation_report.md` and add observations from your SHAP plots.
10. If required, create a GitHub repository and upload the project files, preserving folder structure.

## Evaluation methodology
- Stratified 80/20 train-test split (random seed 42)
- Random Forest classifier (300 trees)
- Precision, recall, F1-score, confusion matrix and ROC-AUC
- SHAP TreeExplainer global and local explanations

## Notes
- SHAP plots are generated by running the notebook because SHAP compatibility varies by environment.
- Built-in feature importance is a baseline and must not be mislabeled as SHAP.
- Educational use only; not for clinical diagnosis or medical decisions.
